# Post LinkedIn - Agent Skills AAIF

Publicado el martes 27/10/2026 a las 14:07 (Madrid). Noticia: Anthropic dona Agent Skills a la Agentic AI Foundation (Linux Foundation).

## Post

```text
Tu agente aprende una tarea una vez y puede usarla en cualquier otro agente. Eso es lo que acaba de quedar asegurado.

Anthropic ha donado Agent Skills a la Agentic AI Foundation, de la Linux Foundation, como ya hizo con MCP.

Una skill es solo una carpeta con un archivo SKILL.md que enseña a un agente a hacer una tarea concreta, y si hace falta, con sus scripts y su documentación.

Según Anthropic:
🔹 Más de 70 plataformas ya lo integran: ChatGPT, Cursor, GitHub Copilot, VS Code…
🔹 1 millón de skills publicadas
🔹 Casi 280 millones de instalaciones

Lo importante es que ahora no es de ninguna empresa. Lo mantienen juntos ingenieros de Anthropic, Google, OpenAI y otras compañías, y cualquiera puede usarlo o contribuir.

MCP para conectar herramientas, Skills para enseñar tareas. La base de los agentes empieza a ser abierta.

Eso sí: una skill son instrucciones y código que tu agente va a seguir. Revísala antes de instalarla.

¿Ya usas skills en tus agentes o sigues yendo prompt a prompt? 👇

#IA #AgentesIA #OpenSource #Anthropic #Automatización
```
