# Ghostty Shortcuts Reference 🔥

Cheat sheet de los atajos principales para Ghostty.

---

## Splits Rápido

```
┌─────────────────────────────────────────┐
│  Alt + V  │  Alt + D  │  Alt + S       │
│  Vertical │ Horizontal│ Open with Nvim │
├─────────────────────────────────────────┤
│  Alt + H/J/K/L → Navegar               │
│  Ctrl+Shift+H/J/K/L → Redimensionar    │
│  Cmd + K → Limpiar pantalla             │
└─────────────────────────────────────────┘
```

---

## Todos los Atajos

### 🔀 Crear Divisiones
| Atajo | Función |
|-------|---------|
| `Alt + V` | Nueva división VERTICAL (derecha) |
| `Alt + D` | Nueva división HORIZONTAL (abajo) |

### 🎯 Navegar Splits
| Atajo | Dirección |
|-------|-----------|
| `Alt + H` | ← Izquierda |
| `Alt + J` | ↓ Abajo |
| `Alt + K` | ↑ Arriba |
| `Alt + L` | → Derecha |

### 📏 Redimensionar
| Atajo | Acción |
|-------|--------|
| `Ctrl + Shift + H` | Expandir izquierda |
| `Ctrl + Shift + L` | Expandir derecha |
| `Ctrl + Shift + J` | Expandir arriba |
| `Ctrl + Shift + K` | Expandir abajo |

### ⚙️ Utilidades
| Atajo | Acción |
|-------|--------|
| `Cmd + K` | Limpiar pantalla |
| `Shift + Enter` | Nueva línea (sin ejecutar) |
| `Alt + S` | Abrir con Nvim |

---

## Ejemplos de Uso

### Ejemplo 1: Dos splits lado a lado
```
1. Alt + V  → Crea división vertical (derecha)
2. Alt + H  → Vuelve al split izquierdo
3. Alt + L  → Regresa al split derecho
```

### Ejemplo 2: Dividir en 4 (2x2)
```
1. Alt + V      → Divide verticalmente
2. Alt + D      → Divide abajo (horizontal)
3. Alt + K      → Sube al split de arriba
4. Alt + D      → Divide arriba también
```

### Ejemplo 3: Redimensionar
```
1. Estás en un split pequeño
2. Ctrl + Shift + H  → Agrandar
3. Ctrl + Shift + L  → Agrandar más
```

## Mnemotecnia 🧠

**Vim-style navigation:**
- `H` = izquierda (como en Vim)
- `J` = abajo (como en Vim)
- `K` = arriba (como en Vim)
- `L` = derecha (como en Vim)

**Splits:**
- `V` = Vertical (derecha)
- `D` = Down (abajo)

**Modificadores:**
- `Alt` = Navegación rápida
- `Ctrl + Shift` = Acciones fuertes (redimensionar)
- `Cmd` = Comandos del sistema (limpiar)
