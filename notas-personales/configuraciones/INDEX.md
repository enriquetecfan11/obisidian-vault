## 🔄 Replicación en Otra Mac

### Paso 1: Instalar programas
```bash
brew install koekeishiya/formulae/yabai
brew install ghostty  # O descargar desde ghostty.org
```

### Paso 2: Crear archivos de config
```bash
mkdir -p ~/.config/yabai
mkdir -p ~/.config/ghostty
```

### Paso 3: Copiar configuraciones
Consulta [[Yabai y Ghostty Setup]] - Sección "Instalación Rápida"

### Paso 4: Iniciar servicios
```bash
yabai --start-service
```
