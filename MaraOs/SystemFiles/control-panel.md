# Control Panel OpenClaw + Obsidian

Archivo HTML del panel de control para configurar OpenClaw + Obsidian manualmente y exportar JSON para Mara.

## Archivo

- HTML principal: `Code/OpenClaw/control-panel.html`
- Copia técnica: `MaraOs/SystemFiles/control-panel.html`

## Uso

1. Abrir `Code/OpenClaw/control-panel.html` desde el explorador de archivos o desde Obsidian si muestra archivos HTML.
2. Ajustar los campos del panel.
3. Pulsar **Exportar configuración para Mara**.
4. Copiar el JSON generado y pasárselo a Mara para aplicarlo/guardarlo.

## Nota operativa

Obsidian puede ocultar archivos `.html` si no está activada la opción de mostrar todos los tipos de archivo. Por eso esta nota `.md` funciona como índice visible dentro del vault.
