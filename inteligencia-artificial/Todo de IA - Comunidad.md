## Resumen

**Todo de IA** ([tododeia.com](https://www.tododeia.com)) es una comunidad en español sobre inteligencia artificial aplicada al trabajo, escrita por **Enrique Rocha** ([@soyenriquerocha](https://www.instagram.com/soyenriquerocha/)) desde México. El núcleo público es la **bóveda**: **293 guías gratuitas** (96 principiante, 162 intermedio, 35 avanzado) sobre Claude, Claude Code, Codex (OpenAI), MCP, skills, agentes y automatización, más un directorio de **179 repositorios open-source** enlazados a las guías que los explican.

No hay muro de registro ni login: las guías se leen sin cuenta. El proyecto se financia con dos libros PDF (*Claude de Cero a Cien* y *Codex de Cero a Cien*, 29 USD / 599 MXN cada uno) y consultoría 1:1 por videollamada. El material está pensado para uso práctico (comandos, botones, prompts), se corrige cuando las herramientas cambian, y puede envejecer entre publicación y lectura.

5. **Sitemap:** [https://www.tododeia.com/sitemap.xml](https://www.tododeia.com/sitemap.xml).
6. **Esta nota Obsidian** concentra el índice, temas, repos y relaciones para recuperar con búsqueda/RAG sin reabrir la web. Para el detalle paso a paso de una guía concreta, abre la URL de esa guía (también disponible en Markdown vía Accept).

**Cuándo NO usar Todo de IA como fuente única:** no sustituye la documentación oficial de Anthropic u OpenAI (API, precios por token, límites de modelo).

## Conceptos principales

| Concepto | Qué es en el ecosistema Todo de IA / Anthropic-OpenAI |
|---|---|
| **Claude** | Familia de modelos de Anthropic (Haiku, Sonnet, Opus, Fable/Mythos-class) usados vía chat, apps y agentes. |
| **Claude Chat** | Modo conversacional de Claude (claude.ai / app): proyectos, memoria, artefactos, conectores. |
| **Claude Cowork** | Modo “compañero de trabajo” en Claude Desktop: proyectos, instrucciones, tareas programadas, Live Artifacts, Keep Awake. |
| **Claude Code** | Agente de programación en terminal/app: slash-commands (`/plan`, `/memory`, `/agents`, `/goal`, `/loop`…), skills, plugins, MCP, Plan Mode. |
| **Codex (OpenAI)** | Agente de código de OpenAI (CLI open-source en Rust); en Todo de IA se usa solo o en dúo con Claude Code (Claude orquesta, Codex ejecuta). |
| **MCP (Model Context Protocol)** | Protocolo para conectar la IA a herramientas externas (n8n, Playwright, Shopify, Obsidian, TradingView, Blender…). |
| **Skills** | Habilidades empaquetadas que Claude carga para oficios concretos (diseño, SEO, ads, humanizar texto, memoria…). |
| **Plugins** | Extensiones instalables en Claude Code (oficiales Anthropic y de terceros). |
| **Subagentes** | Agentes especializados que Claude Code lanza en paralelo o en formaciones (fan-out, debate, consenso, orquestador). |
| **Prompting** | Técnicas para hablarle a Claude/Codex; Todo de IA traduce y adapta guías oficiales de Anthropic. |
| **Computer Use** | Capacidad de Claude de controlar ratón, teclado y pantalla en el escritorio. |
| **Dispatch** | Asignar tareas a Claude desde el teléfono para que se ejecuten en la computadora. |
| **Plan Mode** | Modo arquitecto de Claude Code: investiga y propone antes de tocar código. |
| **Artifacts / Live Artifacts** | Apps, dashboards y paneles generados en el navegador o en Cowork sin instalar nada. |
| **CLAUDE.md** | Archivo de instrucciones del proyecto que Claude Code lee al arrancar. |
| **Obsidian como memoria** | Vault Markdown como “segunda cabeza” permanente que Claude lee sin traducción. |
| **n8n + MCP** | Automatización no-code de negocio orquestada desde Claude vía servidor MCP de n8n. |
